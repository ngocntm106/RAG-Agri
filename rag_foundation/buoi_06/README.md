# Buổi 06 - Demo RAG

Project demo nhỏ, dễ đọc cho workshop.

## File chính
- app.py: giao diện Streamlit đơn giản
- rag.py: module xử lý demo RAG
- requirements.txt: dependency cần thiết
- .env.example: biến môi trường mẫu

## Cài đặt
```powershell
pip install -r requirements.txt
```

## Chạy
```powershell
streamlit run app.py
```
